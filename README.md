# CipherChat

A privacy-first, production-ready, end-to-end encrypted messaging platform built with React, FastAPI, PostgreSQL, Redis, and modern cryptography.

## 🚧 Status

Currently under active development.

## Planned Features

- Email OTP Authentication
- End-to-End Encryption
- Real-Time Messaging
- Group Chats
- Voice & Video Calls
- Secure File Sharing
- Multi-device Support
- JWT Authentication
- Redis Caching
- Docker Deployment

## Tech Stack

### Frontend

- React
- TypeScript
- Tailwind CSS
- Socket.IO

### Backend

- FastAPI
- PostgreSQL
- Redis
- SQLAlchemy

### Security

- X25519
- Ed25519
- AES-256-GCM
- JWT
